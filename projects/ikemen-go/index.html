IkemanGoAss

Ikemen GO fighting game prototype

An Ikemen GO fighting game prototype: two playable characters (The Sword Saint and Unknown) sharing one moveset, and a stormy bridge stage (Broken Bridge). Ikemen GO is the open-source, MUGEN-compatible fighting game engine.
